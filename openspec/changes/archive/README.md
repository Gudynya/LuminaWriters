# Archivo de cambios (`archive/`)

Cada carpeta `YYYY-MM-DD-<nombre-cambio>/` es un **cambio OpenSpec cerrado** movido desde `openspec/changes/<nombre>/`.

Se conservan el `.openspec.yaml` y los artefactos (`proposal.md`, `design.md`, `tasks.md`, etc.) tal cual, para auditoría y referencia histórica.
