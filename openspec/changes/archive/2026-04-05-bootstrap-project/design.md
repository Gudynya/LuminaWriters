# Diseño: bootstrap-project

- Un único `config.yaml` con `context` multilínea apuntando a `app/` y convenciones Flutter.
- Capacidades `product` y `client` como `spec.md` separados para no mezclar negocio y detalle técnico.
- `changes/README.md` explica el ciclo de vida; la carpeta `changes/archive/` aloja cierres.
